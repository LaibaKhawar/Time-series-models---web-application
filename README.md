# Time Series Models Web Application

An educational implementation and experiment exploring **time series models web application**. This repository preserves the original work while adding the structure and documentation needed to understand, reproduce, and extend it.

## What this project demonstrates

- A practical implementation of the core technique or system
- Reproducible source material and experiment flow
- Clear separation between inputs, processing, and outputs
- A foundation for further evaluation and improvement

## Contents

- `maincode.ipynb`

## Technology

matplotlib, numpy, pandas, plotly, pmdarima, prophet, scikit-learn, seaborn, statsmodels, tensorflow

## Getting started

```bash
git clone https://github.com/LaibaKhawar/Time-series-models---web-application.git
cd Time-series-models---web-application
```

Create an isolated Python environment and install the dependencies:

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

Run the project:

```bash
jupyter notebook
```

## Reproducibility notes

Some experiments require datasets or model weights that are not committed because of size or licensing restrictions. Paths should be configured locally before execution. Randomized experiments may produce slightly different metrics across environments.
